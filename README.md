# Amazon Sales Analysis - Python Project

This project explores and Visualizes Sales data from Amazon to uncover key insights about product performance, customer ratings, pricing trends and category-based sales Distribution.

# Project Structure

project amazon sales report.ipynb # Main analysis notebook

Amazon Sales Report.csv # Raw dataset

# Performed Exploratory Data Analysis (EDA)

# Key Insights 

- Surat city has Maximum Orders.
- Most of the Quantity buys are M-Size.
- Majority orders are shipped through Courier.
- Most of the Buyers are Shirt and T-Shirt.
- 99.3% of buyers are Retailers and 0.7% are B2B buyers.
- Most of the buyers are from Maharashtra state.
